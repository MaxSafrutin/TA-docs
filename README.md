# Титан Авто — документы

Откройте index.html в браузере. Он запускает приложение из папки «Новая версия». Этот путь сохранён для доступа к прежним настройкам и профилям в том же браузере.

## Публикация на GitHub Pages

Загрузите всё содержимое этой папки, включая папку «Новая версия», .gitignore и .nojekyll. В настройках GitHub Pages выберите публикацию из корня ветки. Сервер, сборка и внешние библиотеки не требуются: приложение содержит необходимые ресурсы и работает локально и на телефоне.

## Заполнение и сохранение

- Общие поля «Характеристик» и «Акта осмотра» заполняются и очищаются в обе стороны. Синхронизируются также даты, топливо, оснащение и оригинальность ПТС.
- Данные покупателя можно оставить пустыми и продолжить. В документах остаются строки для заполнения от руки.
- Телефон продавца используется в договоре поручения и связанных документах; в ДКП между физическими лицами он не выводится.
- Дубли характеристик убраны из формы. Дополнительные характеристики для объявлений находятся в свёрнутом необязательном блоке.
- Word сохраняет редактируемый текст и таблицы. Изображениями остаются только графические элементы.
- JSON сохраняет данные автомобиля, участников, документов и реквизиты для обмена с другими проектами. Файл можно загрузить с компьютера или телефона, дополнить и сохранить снова.
- Настройки и профили сохраняются в браузере. Для переноса и резервного хранения используйте JSON. У локальной и опубликованной версии отдельные хранилища браузера.

Личные JSON и заполненные документы не загружайте в публичный репозиторий. В этой папке находятся только файлы приложения. Исходники разработки, проверки и прежние версии сохранены в отдельной папке архива рядом с проектом.
